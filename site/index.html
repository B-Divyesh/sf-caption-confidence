Privacy and limits

Know what the extension reads

It reads
Caption files you choose and caption tracks exposed by the current page.

It does not create
The extension does not make captions when a page has no accessible track.

It marks caption text and timing patterns. It does not diagnose hearing loss.

Chrome extension

Install the extension package

Install the supplied Manifest V3 package in Developer mode.

Download extension ZIP
  1. Unzip the download.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose “Load unpacked” and select the unzipped folder.

The package requests the active page, local settings, and access to web pages with video.
